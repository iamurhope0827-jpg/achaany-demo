# Log22 — туршилтын хувилбар

Хүргэлтийн захиалгын системийн туршилтын (demo) сайт.

- Бүртгүүлэх эсвэл туршилтын бүртгэлээр нэвтэрнэ:
  - `admin123` / `admin123` — захиалагч (админ)
  - `jolooch1` / `driver123` — үндсэн жолооч (Сүхбаатар дүүрэг)
  - `jolooch2` / `driver123` — чөлөөт жолооч
- Сервергүй хувилбар тул бүх мэдээлэл зөвхөн таны хөтөч дээр (localStorage) хадгалагдана.
- Газрын зураг: Google Maps. Хаягийн хайлт нь app-config.json дахь серверийн /api/places/search үйлчилгээг ашиглана. Өмнөх захиалгуудаас сурсан газрууд Log22 тэмдэглэгээтэй эхэнд гарна.
- Хайлтаас зөвхөн газрын нэр, нийтийн хаяг, цэг болон эх сурвалж ирнэ. Сервер ажиллахгүй үед Photon хайлт руу шилжиж, энэ тухай мэдэгдэнэ. Захиалга болон бүртгэл нь demo хувилбарын localStorage-д хэвээр хадгалагдана.
